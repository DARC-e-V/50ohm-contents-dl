## Q-Gruppen

* bestehen aus drei Buchstaben und beginnen mit *Q*
* wurden für die schnelle Telegrafie entwickelt
* werden heute auch im Sprechfunk verwendet
* mit Fragezeichen meist eine Frage, ohne Fragezeichen eine Aussage oder Aufforderung

--- style="font-size: smaller;"

### Wichtige Q-Gruppen

| l: Gruppe | X: Bedeutung |
| QRM | Ich werde durch andere Stationen gestört |
| QRN | Ich werde durch atmosphärische Störungen beeinträchtigt |
| QRO? | Soll ich die Sendeleistung erhöhen? |
| QRT | Stellen Sie die Übermittlung ein |
| QRV | Ich bin bereit |

--- style="font-size: smaller;"

### Weitere wichtige Q-Gruppen

| l: Gruppe | X: Bedeutung |
| QRX? | Wann werden Sie mich wieder rufen? |
| QRZ? | Von wem werde ich gerufen? |
| QSB? | Schwankt die Stärke meiner Zeichen? |
| QSL? | Können Sie den Empfang bestätigen? |
| QSO? | Können Sie mit einer bestimmten Station verkehren? |
| QTH | Mein Standort ist ... |

<note>
Merkhilfe: QRM ist eine menschengemachte Störung, QRN eine natürliche Störung und bei QSB geht die Signalstärke bergauf und bergab.
</note>
